## 🔬 Featured Projects

### 🧠 [Alzheimer's Disease Classification via Deep Learning](https://github.com/AbdurRahmanGrami/Classification-of-Alzheimer-s-disease-using-MRI-data-based-on-DeepLearning-Techniques)
MRI-based binary classification of Alzheimer's disease using five deep learning architectures. Implemented and benchmarked CNN, CNN-LSTM, CNN-SVM, and VGG16 transfer learning pipelines on 6,400 MRI images.

- 🏆 Best model: **CNN-LSTM with augmentation — 99.92% accuracy**
- Techniques: Data augmentation, transfer learning, SVM classifiers, FAISS-style feature extraction
- Stack: `Python` `TensorFlow/Keras` `Jupyter` `VGG16`

### 🤖 [Jazz Telecom RAG Chatbot](https://github.com/AbdurRahmanGrami/Jazz_Chatbot)
Production-style AI customer support chatbot for Jazz Pakistan, answering queries about telecom packages using a full RAG pipeline — from data scraping to deployed REST API.

- Semantic search over telecom FAQs and offer documents using FAISS + SentenceTransformers
- Multi-turn conversation memory with SQLite session storage
- Switchable LLM backends: Azure OpenAI, Together AI, Mistral
- Stack: `Python` `LangChain` `FAISS` `FastAPI` `SQLite` `Chainlit`

### 🧩 [DyslexAI: AI-Powered Dyslexia Support System](https://github.com/AbdurRahmanGrami/dyslexai-mobile)
End-to-end AI system designed to assist dyslexic learners by recognizing handwritten text, correcting dyslexia-specific writing errors, and generating personalized learning feedback through adaptive AI modules.

- Hybrid OCR pipeline for dyslexic handwriting recognition using character-level and word-level models
- AI-powered text correction with seq2seq transformers trained on dyslexia-specific error patterns
- Personalized learning engine with error profiling, progress tracking, and gamified practice exercises
- Full-stack web/mobile platform with analytics dashboard and dyslexia-friendly UI
- Stack: Python TensorFlow/PyTorch OpenCV React FastAPI Firebase Docker
